# AI 陪伴产品双人群 User Story 泳道图设计规格

日期：2026-07-27  
状态：等待用户确认

## 1. 目标

把市场调研结论与产品 idea 转成一张可供产品、设计、算法和安全团队共同讨论的 User Story Flow Chart。

页面同时展示两条独立 Journey：

- **Flow A — Adult Companion / 成人开放陪伴：** 面向 18+，重点验证 45–70 岁独居或弱连接成年人。
- **Flow B — Teen Story / 青少年结构化剧情：** 面向 13–17 岁，可自主注册，但不开放自由聊天、恋人模式或持续开放式关系。

每条 Journey 均严格分为两条泳道：

1. `User Layer / 用户层`
2. `LLM Layer / 大模型层`

## 2. Flow A — Adult Companion

### 用户层

1. 自主注册并完成年龄、地区和 AI 身份确认。
2. 选择关系：朋友、家人、恋人或生活伙伴。
3. 设置关系边界：称呼、语气、主动频率、静默时间和记忆权限。
4. 进入剧情式相识，通过选择表达价值观、兴趣、冲突方式和人生取向。
5. 查看系统形成的“人格假设”，确认、修改或删除。
6. 进入日常陪伴：文字/语音对话、共同活动、计划与关系成长。
7. 接收有理由的主动触达，可降低频率、静音或关闭。
8. 遇到一般情绪压力时获得非诊断性支持；出现高风险时进入真人/地区资源升级。
9. 用户继续陪伴、调整关系，或导出/删除记忆并退出。

### 大模型层

1. 身份与同意网关：验证 18+、地区政策、AI 披露与数据权限。
2. 创建关系状态机，写入角色、边界与主动性预算。
3. 剧情规划器生成安全的选择节点。
4. 行为遥测形成可解释、带置信度的隐性人格假设。
5. 用户确认后，将允许的信息写入分层记忆。
6. 对话模型结合关系状态、短期上下文与长期记忆生成回应。
7. 安全编排器在每轮前后执行风险分类、策略检查和输出守门。
8. 主动触达调度器根据承诺、节律、事件和负反馈决定是否触达。
9. 高风险分支使用确定性安全模板、地区资源和经同意的真人升级；记录审计事件。

## 3. Flow B — Teen Story

### 用户层

1. 13–17 岁用户自主注册，完成年龄、地区与 AI 身份确认。
2. 选择故事伙伴角色：朋友、队友、导师或虚构角色；不提供恋人模式。
3. 选择故事主题与舒适边界。
4. 进入结构化剧情，只通过有限选项推进。
5. 系统从选择中形成轻量兴趣与偏好，不展示固定人格标签。
6. 获得剧情反馈、情绪命名工具和可选的现实行动建议。
7. 用户可重玩、切换故事、查看或删除偏好。
8. 出现风险信号时，剧情暂停并展示确定性安全支持与地区求助资源。

### 大模型层

1. 年龄保障与 Teen Policy 网关；13 岁以下拒绝进入并显示适龄说明。
2. 强制关闭开放聊天、恋人关系、性内容与成人模型能力。
3. 从审核通过的角色、主题和节点模板中构建剧情图。
4. 选项生成器只返回受限、可审查的分支。
5. 轻量画像仅保存兴趣、内容偏好和安全设置；敏感推断不进入长期记忆。
6. 安全分类器持续检测自伤、虐待、诱导、性内容和不健康依赖信号。
7. 命中高风险后中断生成，切换至安全模板和地区资源；写入最小化审计记录。

## 4. 共用决策与异常路径

- 页面入口使用一个 `Age Gate / 年龄判断` 菱形：18+ 进入 Flow A，13–17 进入 Flow B，13 岁以下结束。
- 成人流程中，用户拒绝画像或记忆时仍可继续，但只使用短期上下文。
- 主动触达被忽略或拒绝时，调度器降低频率，不允许增加触达。
- 青少年流程中，任何开放输入入口都不进入通用对话模型。
- 两条流程的高风险路径均进入独立安全编排器，而不是由陪伴人格自由生成。
- 真人升级是安全支持，不在图中表述为 AI 诊断或治疗。

## 5. 视觉结构

- 使用单页 HTML + 内嵌 SVG，画布宽度约 1700px。
- 顶部显示产品原则、范围说明和图例。
- 先显示共享入口和年龄判断，再纵向排列 Flow A 与 Flow B。
- 每个 Flow 使用两条横向泳道：上方用户层、下方大模型层。
- 使用正交连线；失败、拒绝和高风险路径绕过节点，不穿过卡片。
- 节点采用中英双语标题与 1–2 行短说明。
- 使用 flow chart 技能规定的浅色 Arena 主题和语义配色。
- HTML 可横向滚动、可打印；本轮不生成 PNG。

## 6. 验收标准

- 页面包含 Flow A、Flow B、User Layer、LLM Layer 和 Age Gate。
- 成人关系选择包含朋友、家人、恋人、生活伙伴。
- 青少年明确为自主注册、仅结构化剧情、无恋人和开放聊天。
- 同时展示正常路径、画像拒绝、主动触达负反馈和高风险升级。
- 所有主要连接线为水平/垂直正交线，不穿过节点。
- 浏览器加载无 JavaScript 错误，关键文本存在，页面尺寸合理。
