AI Native 持续关系循环

一次设置，持续共创。用户的每次聊天、语音、剧情选择和小游戏行为都会进入可审核的 Agent 决策链路，形成新的回复、动作、剧情、关系状态与后续陪伴。

User Layer / 用户层 Agent & LLM System Layer / Agent 与大模型系统层 关系状态驱动内容生成 AI companionship · not therapy
Experience loop / 每次互动留下可控后果 用户输入不只获得一句回复，还可能带来新的动作、剧情、关系变化与后续联系；用户始终可以查看、修改或退出。
State governance / 状态变更必须审核 LLM 只提出关系和记忆变化；规则系统依据年龄、边界、同意与反操控策略审核后才允许落库。
Safety boundary / 主动陪伴不制造依赖 忽略或拒绝只会降低触达频率，不降低关系等级，不制造内疚，也不以付费刺激亲密度。
User action / 用户动作 Agent decision / Agent 决策 State & memory / 状态与记忆 Policy decision / 策略判断 Next safe experience / 下一次安全体验 Pause or support / 暂停或支持
