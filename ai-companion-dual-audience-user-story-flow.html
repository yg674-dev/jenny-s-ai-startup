成人开放陪伴 × 青少年结构化剧情

同一产品愿景，两套相互隔离的体验与模型链路。Flow A 服务 18+ 成人，重点验证 45–70 岁的 voice-first 长期陪伴；Flow B 允许 13–17 岁自主注册，但仅提供结构化剧情，不开放恋人模式与自由聊天。

User Layer / 用户层 LLM Layer / 大模型层 关系选择 + 隐性画像 + 剧情 + 安全 + 主动陪伴 非诊断性情绪支持
成人：关系契约先于亲密度关系、边界、记忆和主动频率均由用户选择；关系状态机不以付费刺激依赖。
青少年：选择代替开放输入自主注册不等于开放聊天。剧情选项来自审核模板与受限生成，风险命中后立即暂停。
安全：独立于陪伴人格风险分类、确定性模板、地区资源、真人支持和审计由 Safety Orchestrator 统一编排。
