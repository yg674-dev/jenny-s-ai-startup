# AI 陪伴产品北美市场研究 HTML 设计规格

日期：2026-07-26  
状态：用户已确认

## 1. 目标

制作一份可本地直接打开的中文单页 HTML 市场研究报告，帮助产品创始人完成以下判断：

1. 北美 AI 陪伴、互动剧情、数字心理健康和老年陪伴机器人市场是否存在真实需求。
2. Replika、Refind Self、Character.AI Stories、Wysa、ElliQ 分别验证了哪些产品能力。
3. 各产品在北美的用户规模或市场份额应采用什么可核验代理指标。
4. 各产品的核心用户画像、盈利方式和模型层实践是什么。
5. 五种能力如何组合为一个可落地的新产品，同时避免未成年人、心理治疗声明和情感依赖风险。

报告是研究与决策材料，不是营销落地页，也不把未经披露的私营公司数据包装成精确事实。

## 2. 交付形式

- 单个自包含 HTML 文件，CSS 和 JavaScript 内嵌。
- 中文为主，保留必要的英文产品名和行业术语。
- 不依赖登录、数据库或构建环境，可用浏览器直接打开。
- 支持桌面端、移动端和打印/PDF。
- 外部链接仅用于引用官方页面、政府文件、研究报告和可信市场数据。
- 页面不使用装饰性图片，以排版、表格、数据卡片和 CSS 图形为主。

## 3. 视觉方向

采用编辑型研究报告风格：

- 暖白背景、深灰正文、低饱和蓝/绿/黄/红作为语义色。
- 中文系统字体搭配编辑型衬线标题，避免依赖在线字体。
- 大留白、细边框、平面卡片，不使用渐变、玻璃拟态或厚重阴影。
- 首页突出三项内容：市场结论、产品机会、最大风险。
- 左侧固定目录用于桌面浏览；移动端转换为顶部章节导航。
- 所有关键数字显示口径、年份、地域和可信度，不单独展示容易误导的“大数字”。

## 4. 信息架构

### 4.1 封面与执行摘要

- 标题、研究范围、日期。
- 五句核心结论。
- 三个市场信号卡片：需求、商业化、监管。
- 一句话产品机会定义。

### 4.2 研究方法与数据口径

- 区分注册用户、MAU、下载量、消费额、付费用户和机构部署。
- 说明私营公司通常不披露北美精确份额。
- 用“公开事实 / 市场代理 / 分析推断”三级标签区分证据类型。
- 对每项份额判断给出高、中、低置信度。

### 4.3 北美市场概览

- AI companion 移动端下载、消费额、增长和收入集中度。
- 美国与加拿大在全球下载和消费中的位置。
- 用户年龄和性别结构。
- 青少年使用率、成年人孤独感、老年独居陪伴需求。
- 不使用定义混乱、金额异常膨胀的泛 AI companion 市场规模报告作为核心依据。

### 4.4 五个标杆产品深拆

每个产品使用完全相同的字段：

1. 产品定位与核心体验。
2. 北美用户规模或市场份额代理。
3. 核心用户画像与典型使用场景。
4. 盈利方式和付费驱动。
5. 用户层关键机制。
6. 模型层或算法层实践。
7. 安全、隐私与监管边界。
8. 对新产品可复用的能力。
9. 不应复制的问题。

产品范围：

- Replika：关系选择、持续关系、Avatar、记忆和订阅分层。
- Refind Self：非 LLM 的隐性人格识别、行为数据和多周目验证。
- Character.AI Stories：结构化生成剧情、角色生态和未成年人开放式聊天替代方案。
- Wysa：规则系统与 LLM 混合、临床审核内容、安全分流和 B2B2C。
- ElliQ：主动陪伴、语音优先、长期节律、照护者连接和软硬件订阅。

### 4.5 横向竞争矩阵

统一比较以下维度：

- 关系自由度
- 人格识别
- 长期记忆
- 剧情结构
- 主动发起
- 心理健康安全
- 未成年人适用性
- 实体存在感
- 真人/照护者连接
- 商业化成熟度
- 北美规模证据

评分只用于相对比较，页面明确说明评分不是临床或投资评级。

### 4.6 用户细分与购买者

拆分三类，而不是把所有孤独用户视为同一人群：

- 18+ 年轻成人及单身成年人：用户本人购买，重视关系、身份表达和连续记忆。
- 45-70 岁单身、离异、丧偶或空巢成年人：用户本人或成年子女购买，重视语音、主动陪伴和生活节律。
- 13-17 岁青少年：青少年使用，家长、学校或医疗机构控制准入和付费，必须采用结构化体验。

明确建议第一阶段不把青少年与成年人放在同一个开放式模型和同一品牌承诺中。

### 4.7 五能力组合后的产品机会

用两层架构展示：

**用户层**

- 关系契约
- 剧情式认识过程
- 日常对话与活动
- 主动陪伴
- 情绪支持与真人求助

**模型层**

- 隐性人格与偏好模型
- 关系状态机
- 长期记忆与用户可编辑事实
- 结构化剧情规划器
- 安全策略与危机分流
- 主动触达调度器
- 同意、年龄和数据权限系统

产品核心定义为“通过共同经历逐步认识用户的主动型 AI companion”，而不是“第一次见面就知道一切的 AI”。

### 4.8 商业模式与进入市场策略

比较三条路径：

1. 成人 D2C 软件订阅：验证最快，竞争最强。
2. 中老年语音设备 + 家庭订阅：客单价更高，硬件和服务成本更高。
3. 青少年 B2B2C 结构化 wellbeing：安全要求最高，销售周期更长。

报告给出推荐顺序：

- 先以 45-70 岁单身或独居成年人做软件/语音 MVP。
- 验证主动陪伴、剧情识别和持续关系后，再考虑轻硬件。
- 青少年产品作为独立产品线，与学校、临床和安全专家共同开发。

### 4.9 监管、安全与伦理

- 美国联邦层面的 FTC/COPPA、FDA 医疗声明边界。
- 州层面的 AI 心理治疗和 companion chatbot 规则。
- 加拿大隐私和未成年人数据要求。
- 年龄确认、危机分流、关系依赖、真人模仿、逝者模拟和产品停服风险。
- 明确建议使用 emotional wellness、self-reflection 和 companionship，而不是 AI therapist。

### 4.10 结论与下一步研究

- 最值得验证的五个产品假设。
- 首轮访谈样本建议。
- MVP 成功指标。
- 仍需通过用户访谈、可用性测试和付费实验验证的未知项。

### 4.11 来源附录

- 官方产品文档。
- 政府、监管和专业协会资料。
- Appfigures、Sensor Tower 等市场代理数据。
- 学术和非营利研究。
- 每个来源标注访问日期。

## 5. 页面交互

- 目录锚点和当前章节高亮。
- 五产品卡片可展开/收起详细模型实践。
- 竞争矩阵支持按“用户层 / 模型层 / 商业层 / 安全层”切换。
- 数据标签可筛选“公开事实 / 市场代理 / 分析推断”。
- 引用链接在新标签页打开。
- 提供“打印报告”按钮。
- 遵守 reduced-motion 设置；无 JavaScript 时仍可阅读全部核心内容。

## 6. 数据与可信度规则

- 没有公开北美份额时，不输出伪精确百分比。
- Character.AI 的 MAU、Replika 的注册用户、Wysa 的全球累计用户、ElliQ 的机构部署和 Refind Self 的销量/评价不可直接互相比较。
- 份额展示使用两部分：
  - 类别中的相对位置：领先、头部、细分领先、利基、案例型。
  - 可比代理：美国下载/收入排名、全球 MAU、累计下载、机构部署或付费模式。
- 所有估算必须注明来源、时间和限制。
- 产品没有使用 LLM 时，明确写“非 LLM 算法实践”，不强行归入大模型。
- 未公开模型供应商、参数、训练数据或安全系统时，写“未公开”，并与分析推断分开。

## 7. 可访问性与质量要求

- 正文对比度满足 WCAG AA。
- 所有交互支持键盘操作并有可见焦点。
- 表格在窄屏可横向滚动，不压缩到不可读。
- 标题层级连续，页面包含跳到正文链接。
- 打印时隐藏导航和交互按钮，保留来源 URL 与数据口径。
- 最终检查无断裂锚点、空章节、占位符、控制台错误或明显布局溢出。

## 8. 不在本次范围

- 不开发真实聊天、登录、支付、数据库或 LLM 接口。
- 不制作投资财务模型或未经验证的 TAM/SAM/SOM 精确预测。
- 不提供法律、医疗或临床建议。
- 不部署公开网站，除非用户后续明确要求。

## 9. 验收标准

1. 一个 HTML 文件包含完整中文报告。
2. 五个产品全部覆盖北美份额代理、用户画像、盈利方式和模型/算法层实践。
3. 所有重要外部数据均有可点击来源和时间口径。
4. 页面在桌面与手机宽度下都能清晰阅读。
5. 打印预览无明显内容截断。
6. 关键结论与数据限制不互相矛盾。
7. 报告能直接支持下一步用户访谈和 MVP 立项讨论。
