# AI Interactive Drama · AI 互动漫剧

A branching visual-novel generator: define a female lead + male lead + world, and AI drafts a full 40-scene tree of illustrated romance, playable end-to-end with zero-latency choices. Bilingual (中文 / English).

**Live sample content shipped in this repo** — 4 pre-generated stories, 387 scenes, 383 illustrations, romance-flavoured, otome art style.

## Product

| Story | Setup | Depth | Scenes |
|---|---|---|---|
| 雨夜书店 · The Rainy Bookstore | 17F student × 19M silver-haired bookkeeper, 1998 Shanghai alley, mysterious shop that only opens on rainy nights | 4-5 layers | 55 |
| 深夜便利店 · Late-Night Convenience Store | 22F night-shift clerk × 26M stoic customer who's come 43 weeks in a row | 4-6 layers | 115 |
| 穿1937 · Transmigrated to 1937 | 26M modern cardiologist blackout on operating table, wakes in 1937 wartime Shanghai next to a young female painter | 4 layers | 118 |
| 重复的八月二十 · The Repeating August 20th | 22M male student relives Aug 20 seventeen times, meets a female classmate who also remembers | 4-5 layers | 99 |

Every playthrough branches on 3-choice decisions at each layer. Choices resolve instantly (all scenes pre-generated when the script is created).

## Stack

- **Framework**: Next.js 15 (App Router), React 19, Turbopack
- **DB**: SQLite via `better-sqlite3` (dev) / Turso (prod-ready), Drizzle ORM
- **LLM**: Volcengine Ark — GLM-5.2 for narrative + branching
- **Image gen**: Volcengine Seedream 4.0, 864×1152 portrait comic panels
- **UI**: Tailwind CSS v4, shadcn/ui, Zustand, next-intl (中/EN)
- **Language**: TypeScript strict, Biome for lint/format

## Architecture highlights

- **Pre-generation, not real-time**: `POST /api/scripts` triggers `buildStoryTree` which recursively generates root → 3 branches → 9 branches (13 scenes) with parallel batches of 3, resolving in ~1-2min. Playthrough is instant.
- **Tree extension**: `scripts/extend-tree.ts` adds one more layer (+27 scenes) to an existing tree. User-approved uneven depth ("game feel" — some paths short, some long).
- **Bilingual content**: each script/node has `_en` columns; UI reads current locale and falls back to Chinese if EN missing. `scripts/translate-all.ts` batch-translates all 387 scenes idempotently.
- **Image caching**: images live at `public/generated/{scriptId}/{nodeId}.png`, served statically. TTL from Doubao is bypassed by immediate download.
- **Character consistency mitigation**: `characterSetup` uses relative height ("male slightly taller than female") to avoid Seedream making the un-specified party miniature.

## Run locally

```bash
pnpm install

cp .env.example .env.local
# then fill DOUBAO_API_KEY (from console.volcengine.com/ark)
# and DOUBAO_LLM_MODEL / DOUBAO_IMAGE_MODEL (your inference endpoint IDs)

pnpm dev
# open http://localhost:3000/zh — Chinese
# open http://localhost:3000/en — English
```

The included `dev.db` has all 4 stories with 387 scenes ready to play (no API calls needed to browse).

To create a new story via the UI, an API key with activated **GLM-5.2** + **Seedream 4.0** is needed. Cost per new 13-scene story ≈ ¥3, 4-layer extension +¥18-24.

## Scripts

| Script | Purpose |
|---|---|
| `scripts/rewrite-stories.ts` | Bulk overwrite scripts with hand-written narratives + regen images (romance rewrite) |
| `scripts/extend-tree.ts` | Extend existing tree by one layer (options generated by LLM per leaf) |
| `scripts/generate-more.ts` | Batch create new scripts from seed data |
| `scripts/translate-all.ts` | Translate all zh content to en (idempotent, safe to re-run) |
| `scripts/seed-yuye-en.ts` | Seed hand-written EN version of 雨夜书店's opening 5 scenes |
| `scripts/rebuild-yuye.ts` | Rebuild 雨夜书店 from existing on-disk images (for DB recovery) |
